# 阶段 8：K12 创造者学习路径试点

本地完成时间：2026-08-12

## 目标

让 6–18 岁学习者不必先理解技术分类，而是从自己的成长阶段和真实兴趣进入一个可完成的作品任务。年龄只提供入口，最终目标是让学习者提出问题、做出决定、完成作品、面对反馈并形成作者记录。

## 试点范围

第一批复用 8 个已核实、无需后端和付费服务的 MIT 开源任务，没有下载或执行新的第三方代码：

| 主要年龄段 | 试点案例 |
| --- | --- |
| 小学低段（6–8 岁） | 记忆翻牌、有性格的猜拳游戏 |
| 小学高段（9–12 岁） | 随机抽签器、三题小测验 |
| 初中（13–15 岁） | 专注计时器、可拖动故事板 |
| 高中（16–18 岁） | 单页项目介绍、研究灵感便签 |

相邻年龄段可以共享推荐，但每个年龄段恰有 2 个主要设计案例。年龄不是能力等级，页面允许随时清空筛选和跨年龄探索。

## 已完成

- `BeginnerMission` 增加兼容的 `1.1.0` 版本，K12 试点必须包含年龄、学科、场景、成人支持和安全信息。
- 每个试点都写明问题、知识、工具、作品、反馈、身份六个环节。
- 每个试点都把人机边界拆成“学习者亲自决定、AI 可以帮助、完成前必须验证”。
- `/start` 支持年龄与作品兴趣组合筛选，并为无结果组合提供恢复入口。
- 任务卡显示主要年龄段和学科，详情页显示完整六环、人机边界与成人安全说明。
- 首页优先展示 K12 试点，主导航把入口明确为“K12 开始”。

## 隐私与安全边界

- 不采集生日、真实年龄、学校、班级和监护人信息。
- 年龄选择只存在于当前页面状态，不写入 `MakerProgressRecord`。
- 小学低段必须有成人支持；公开素材、人物信息和同伴数据都给出具体限制。
- 作品记录继续仅保存在本机，公开网址仍是可选字段。

## 验收

- 8 个试点全部通过运行时 Schema。
- 四个主要年龄段各 2 个案例。
- 小学低段“无需成人支持”、`1.1.0` 缺少 K12 设计等非法数据会被测试拒绝。
- 全量测试、TypeScript 检查和生产构建通过。

## 下一阶段建议

阶段 9 优先把这 8 个案例组织成可真实试教的主题路线和教师/家长引导卡，先获得完成率、卡点和作品质量反馈。账号、云端儿童档案、排行榜和社区继续延后，避免在学习设计未经验证前固化用户画像。
