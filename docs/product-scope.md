# 产品范围：MVP

## 产品命题

开源雷达是一张帮助 vibe coding 初学者“找到案例、看懂案例、复刻案例”的学习地图，不是另一个 GitHub Trending。

## 首要用户

已经开始使用 AI 编程工具、能够描述想做的产品，但尚不熟悉完整应用结构的学习者。

## 核心任务

用户应能在三步内完成：

1. 按“我想做什么”或“我想学什么”找到候选项目。
2. 判断项目难度、前置条件和学习价值。
3. 进入 30 分钟、2 小时或 1 天的复刻路径。

## MVP 范围

- 首页：精选、分类入口、新收录项目。
- 发现页：关键词、类型、技术栈、学习目标和难度筛选。
- 项目页：仓库事实、中文策展内容、学习路径和风险提示。
- 方法页：准入、评分、数据时间与 AI 使用说明。
- 数据管线：自动发现并形成候选，审核后才可发布。
- 首批内容：5 个纵向样板，验收后扩展到 30 个项目。

## 明确不做

- 登录、收藏、评论、用户投稿和社区系统。
- 个性化推荐和用户能力画像。
- 复杂管理后台和生产数据库。
- 自动把候选项目直接发布到公网。
- 下载或执行被分析仓库的未知代码。

## MVP 成功判据

- 30 个项目全部通过 Schema 和内容审核。
- 至少覆盖 6 类项目与 8 种学习目标。
- 用户最多三步进入一个可执行学习路径。
- GitHub 抓取失败不会破坏上一版已发布内容。
- 页面构建不依赖实时 GitHub API。

## 发布边界

本地开发、测试和预览不等于发布授权。任何公网部署、外部内容发布或生产配置写入都需要单独、明确授权。
