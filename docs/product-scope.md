# 产品范围：MVP

## 产品命题

OpenVibe Atlas 是一张帮助 vibe coding 初学者“找到案例、看懂案例、复刻案例”的学习地图，不是另一个 GitHub Trending。

## 首要用户

已经开始使用 AI 编程工具、能够描述想做的产品，但尚不熟悉完整应用结构的学习者。

## 核心任务

产品现在分为两层路径：

1. 新手层：先在 15 分钟内看到改动，2 小时内完成一个可署名分享的小作品。
2. 进阶层：再按想做什么、想学什么找成熟项目，进入 30 分钟、2 小时或 1 天的拆解路径。

用户应能在三步内完成：

1. 选一个自己真想做的作品任务。
2. 完成第一个可见变化，并为作品做出一个不能外包给 AI 的决定。
3. 按三段路径完成、署名并展示作品，再进入进阶项目库。

## MVP 范围

- 首页：精选、分类入口、新收录项目。
- 新手开始：个人页、小工具、交互练习和小游戏四条作品路线。
- 发现页：关键词、类型、技术栈、学习目标和难度筛选。
- 项目页：仓库事实、中文策展内容、学习路径和风险提示。
- 方法页：准入、评分、数据时间与 AI 使用说明。
- 数据管线：自动发现并形成候选，审核后才可发布。
- 首批内容：5 个纵向样板，验收后扩展到 30 个项目。

## 明确不做

- 登录、收藏、评论、用户投稿和社区系统。
- 个性化推荐和用户能力画像。
- 复杂管理后台和生产数据库。
- 自动把候选项目直接发布到公网。
- 下载或执行被分析仓库的未知代码。

## MVP 成功判据

- 30 个项目全部通过 Schema 和内容审核。
- 至少 12 个新手任务通过独立 Schema，并全部满足 15 分钟首次变化、2 小时完成和零付费服务门槛。
- 至少覆盖 6 类项目与 8 种学习目标。
- 用户最多三步进入一个可执行学习路径。
- GitHub 抓取失败不会破坏上一版已发布内容。
- 页面构建不依赖实时 GitHub API。

## 发布边界

本地开发、测试和预览不等于发布授权。任何公网部署、外部内容发布或生产配置写入都需要单独、明确授权。
