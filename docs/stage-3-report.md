# 阶段 3：新手作品入口

完成日期：2026-08-11。

## 结果

OpenVibe 已从“先看成熟项目”调整为两层产品：

- 第一层是 13 个低门槛作品任务，优先让初学者获得作者经验。
- 第二层是原有 30 个审核过的成熟开源项目，作为进阶案例库。

首页的首要行动改为“开始第一个作品”，不再让初学者先面对框架、数据库、认证和部署等系统性复杂度。

## 新手准入门

每个任务都通过 `BeginnerMissionSchema`，并满足：

- 15 分钟内能看到第一个改动。
- 120 分钟内能做出可分享版本。
- 不依赖后端、付费 API 或付费平台。
- 源项目有 MIT 许可证，并记录仓库、目录和核对日期。
- 只有三段任务，每段都有具体动作和完成标志。

13 个任务覆盖个人网页、小工具、交互练习和小游戏四条路线。

## AI 协作边界

每个任务同时给出：

- 一个可直接复制给 AI 的分步协作提示词。
- 一个必须由学习者亲自完成的 `makerDecision`。
- 一个署名与真实展示的收尾动作。

这使 AI 的角色限定为定位、解释与实现协助，而不替代学习者的意图、价值判断和作者责任。

## 新增路由

- `/start`：新手任务总览和四条作品路线。
- `/start/[slug]`：独立任务卡、第一个改动、三段路径、AI 提示词和源项目依据。

## 下一阶段

阶段 4 将建立持续更新闭环：

1. 定时执行发现与快照更新，但不自动公开发布。
2. 识别新候选、仓库变化、许可证变化和长期不活跃项目。
3. 生成待审队列和变更摘要，由人工或已授权 Agent 审核。
4. 审核通过后生成新的静态版本，再触发部署。

生产数据库、订阅通知和公网部署仍属于后续阶段，本阶段未执行任何远程写入。
