# 阶段 4：持续更新闭环

完成日期：2026-08-11。

## 闭环

```text
每周只读检查 → 待审候选快照 → 风险分类 → 显式审核
                                              ↓
                           快照 + 发布 bundle + 审核记录 + RSS
```

## 已完成

- 新候选搜索与已发布仓库检查每周独立运行。
- 更新扫描使用 ETag 与串行请求，失败不覆盖上一版队列。
- 可识别仓库改名、分支、介绍、许可证、README、技术栈、活跃度、指标、可用性和长期停更。
- 许可证和可用性变化不能被普通批准。
- 批准后同步站点事实、审核记录和公开更新历史。
- 新增 `/updates` 更新日志和 `/updates/feed.xml` RSS 订阅源。

## 安全边界

本阶段没有自动提交、自动批准、自动部署、邮件发送或生产数据库写入。RSS 不收集订阅者信息。

邮件订阅将在阶段 5 部署时，配合数据库、同意记录、退订机制和发送域名一起实施。
